# Currency icons

These 64×64 PNGs are placeholders generated by [`scripts/generate_placeholder_icons.py`](../../../scripts/generate_placeholder_icons.py). Each is a flat color disc with a single capital letter to make them visually distinguishable in-game while final art is being commissioned.

| File | Used for | Placeholder color | Glyph |
|---|---|---|---|
| `coin.png` | Gold currency chip | Brass | G |
| `rancher_point.png` | Rancher Points chip | Pale blue | R |
| `prestige.png` | Prestige currency chip | Ruby | P |

**To replace with final art:**

1. Save the new PNG over the existing file with the **same filename and dimensions** (64×64 recommended; the chip layout assumes square).
2. Keep transparent background (`RGBA`).
3. Re-import via Godot Editor or by deleting the corresponding `.import` file and re-opening the project.

To regenerate placeholders (overwrites in place):

```sh
python scripts/generate_placeholder_icons.py
```
